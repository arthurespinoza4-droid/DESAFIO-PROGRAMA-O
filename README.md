## Resumo dos Conceitos Praticados

Durante a realização do exercício **“Construa um app de fotos de gatinhos”**, no freeCodeCamp, aprendi a utilizar a linguagem **HTML** para criar e organizar o conteúdo de uma página web. Foram praticadas tags para títulos, parágrafos, imagens, links e listas, compreendendo melhor como cada elemento contribui para a estrutura da página.

A principal dificuldade foi entender a organização correta das tags e seus atributos. As estruturas mais utilizadas foram as **tags HTML**, como `<h1>`, `<p>`, `<img>`, `<a>`, `<ul>` e `<li>`, além da utilização de atributos como `src` e `href`. O exercício ajudou a compreender melhor os fundamentos necessários para criar páginas web.
